# Architecture Decision Records

Формат Майкла Найгарда: **Статус, Контекст, Рішення, Наслідки**, плюс розділ
**Альтернативи** з trade-offs. Один ADR на одне рішення. Прийнятий ADR не редагується по суті:
якщо рішення змінюється, пишемо новий ADR зі статусом «Замінює ADR-NNN».

Статуси: `Запропоновано`, `Прийнято`, `Відхилено`, `Застаріло`, `Замінено ADR-NNN`.
